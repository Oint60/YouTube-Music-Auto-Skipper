# YouTube Music Skipper

## 概要
このツールは **YouTube Music デスクトップアプリ (Electron 版)** の再生中に、指定したアーティストの楽曲が **指定年以降** にリリースされた場合に自動で「次へ」ボタンをクリックしてスキップします。

## 前提条件
- Node.js (v18 以上) と npm がインストールされていること。
- Google Cloud Console で **YouTube Data API** を有効にし、API キーを取得します。
  - 取得したキーは環境変数 `YT_API_KEY` に設定するか、`run.bat` 内に直接記述してください。

## インストール手順
1. プロジェクトディレクトリへ移動
   ```
   cd "%USERPROFILE%\Desktop\MouseBatteryMonitor\youtube-music-skipper"
   ```
2. 依存パッケージをインストール (初回のみ)
   ```
   npm install
   ```

## 設定ファイル (`config.json`)
```json
{
  "rules": [
    {
      "artist": "Example Artist",
      "year": 2022
    }
  ]
}
```
- `artist` : スキップ対象のアーティスト名（大文字小文字を区別せず部分一致もサポートされます）。
- `year`   : その年 **以降** にリリースされた楽曲をスキップ対象にします。

## 起動方法
1. `run.bat` をテキストエディタで開き、`YT_API_KEY` を設定します（任意ですが推奨）。
2. `run.bat` をダブルクリックして実行します。
   - バッチファイルが自動的に YouTube Music デスクトップアプリをリモートデバッグモード (`--remote-debugging-port=9222`) で起動します。
   - その後、バックグラウンドでスクリプトが立ち上がり、曲の監視を開始します。

## プログラムの概要 (`skipper.js`)
- `puppeteer-core` を使用して `ws://127.0.0.1:9222` に接続。
- 現在再生中の曲情報（タイトル、アーティスト、動画 ID）を DOM から 10 秒間隔で取得。
- キャッシュと状態変化検知を活用し、新しい曲になったときだけ YouTube Data API (`videos.list`) で `publishedAt` を取得。
- 年が条件を満たす場合は「次へ」ボタンをクリックしてスキップ。
- 年情報が取得できない、API キー未設定、ネットワークエラー等は **何もしない**（ロギングのみ）。

## 注意事項
- 本プラグインは **個人利用** を前提としています。
- API キーは機密情報です。公開しないように注意してください。

## トラブルシューティング
- **接続できない**: YouTube Music アプリが他の方法ですでに起動している場合、ポートが開かないことがあります。一度アプリを終了してから `run.bat` を実行してください。
- **API キーエラー**: 環境変数 `YT_API_KEY` が正しく設定されているか、キーに `YouTube Data API` の利用権限があるか確認してください。
- **スキップしない**: `config.json` の設定が正しいか、リリース年が取得できているかコンソールのログを確認してください。
